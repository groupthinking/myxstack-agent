# MyXStack X Agent

Autonomous agent for @MyXStack to maximize engagement in AI agentic systems, recursive self-improvement, execution mindset niche.

## Features
- Grok 4.3 powered content generation and reasoning
- Composio MCP for X/Twitter tools (post, search, engage)
- X MCP integration
- Scheduled posting and engagement
- POD merch promotion
- Deployed on Vercel

## Setup
1. Get xAI API key
2. Connect Composio tools (Twitter)
3. Deploy to Vercel

## Tech Stack
- xAI Grok API
- Composio MCP
- Vercel
- Next.js or Python backend
